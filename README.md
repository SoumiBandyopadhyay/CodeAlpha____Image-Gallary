# 🌌 Space Image Gallery

A responsive and interactive image gallery built using **HTML, CSS, and JavaScript**.  
It includes category filtering, lightbox view, and smooth hover effects.

---

## 📜 License

This project is for learning and educational purposes.

----
## ✨ Features

- 📱 Fully responsive grid layout
- 🖼️ 50+ images (Nature, Space, Flowers)
- 🔍 Category filtering system
- 💡 Lightbox view (click to enlarge images)
- ⬅️➡️ Next / Previous navigation in lightbox
- 🎨 Smooth hover animations
- 🌌 Space-themed background design
- ⚡ Lightweight (no external libraries)

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid, Animations, Transitions)
- JavaScript (DOM Manipulation)

## 🚀 How to Run

1. Download or clone the repository (https://github.com/SoumiBandyopadhyay/CodeAlpha____Image-Gallary)
2. Open `index.html` in any browser
3. Click images to view in fullscreen mode
